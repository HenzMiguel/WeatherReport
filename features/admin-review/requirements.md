# Administrative panel — Review

- Validate that only authenticated administrators can access system metrics and generated-error details.
- Validate that requests, errors, CPU, and memory each render as a 60-minute chart with an explicit reference period.
- Validate that generated errors expose the timestamp, method, route, and HTTP status without exposing query parameters or request bodies.
- Validate clear loading, access-denied, and API-error states in the administrative interface.
