# Weather Report

This application should be a black and white, with minimal css, Weather report website.

# Actors
- Admin
- User

# Pages

## Dashboard

### Features
- Localização inferida por GPS
- temperatura: diferença da temperatura de hoje para ontem e temperatura de hoje
- risco (se houver) para esta semana
- gráficos: temperatura do dia atual até uma semana atrás
- Buscar temperatura, gráficos e risco manualmente por cidade/estado

## Mapa

### Features
- Mapa é o Brasil
- severidade como pontos no mapa

## Rankings
Por estado e cidade do Brasil. Deve mostrar curiosidades sobre o clima atual, como o estado ou cidade mais úmido, mais quente, mais frio e outras comparações.

### Features
- anomalias
- tendências
- Maior e menor

## Admin dashboard

### Features
- Quantidades de requisições ao longo do tempo
- Quantidade de erros
- Porcentagem da CPU utilizada
- Memória consumida
